# Validaciones de la Agenda Inteligente ## Validación 1: Actividad vacía **Objetivo:** evitar que el usuario registre una actividad sin nombre. **Dato de entrada:** Campo de actividad vacío. **Resultado esperado:** El sistema debe mostrar un mensaje indicando que se debe ingresar una actividad. ## Validación 2: Actividad con información **Objetivo:** comprobar que se pueda registrar una actividad correctamente. **Dato de entrada:** Una actividad con información válida. **Resultado esperado:** La actividad debe registrarse y aparecer en la agenda. ## Validación 3: Información incompleta **Objetivo:** evitar que se registren actividades con datos necesarios faltantes. **Resultado esperado:** El sistema debe solicitar al usuario completar la información requerida.
